Find the weakness. Check it. See why.

A scanner that retrieves OWASP and CWE evidence for every function in a repository, has a language model check each match, and shows every score behind the result. It reads Python, JavaScript/TypeScript, Java, Kotlin, PHP, Go, C#, Ruby, C/C++ and Rust, and it runs on plain Python.

How a scan works

Retrieval and rules propose candidates and reasons. A model judges only after that, and severity comes from a fixed table, not from the model.

IngestGitHub URL, folder or zip; vendored and binary files skipped
Parsetree-sitter splits code into function-level units
EmbedGloVe-100 vectors weighted by IDF
IndexFAISS for the knowledge base and for the repo
Retrievedense + BM25 + sink rules + prior, fused into one score
JudgeLLM returns a JSON verdict with evidence and confidence
Scoreconfirmed, needs review or rejected, with a CVSS band
Fix63 fix patterns plus the model's own before and after
StoreSQLite, with JSON, CSV and SARIF export
ShowReact dashboard with an Inspector for every score

Results

Does the correct CWE come back from the 269-entry knowledge base? Measured on 128 snippets (61 Python and JavaScript, 67 in eight other languages) written after the sink rules were frozen.

RetrieverTop-1Top-6
Dense (averaged GloVe) only17.2%39.8%
BM25 only46.9%82.8%
Sink rules only85.9%95.3%
Full system79.7%96.9%
The rules carry most of the accuracy. Dense and BM25 add recall: with BM25 removed, top-6 falls from 96.9% to 89.8%. The 95% Wilson interval on the full system's top-1 is 71.9 to 85.7.
Four real scans on the Groq free tier took 13 to 23 minutes each and produced 100 confirmed findings in total. The targets have no ground-truth labels, so that figure is a count and not an accuracy.

What you see

The Inspector breaks a match into its parts, so a reviewer can see why an entry ranked where it did.

Run it

Python 3.10 to 3.14. No compiler, no GPU, no model download. A free Groq or Gemini key is optional; without one, findings stay marked Unverified.

git clone https://github.com/aakashsivakumar20/RAG-vuln-detection.git
cd RAG-vuln-detection
./setup.sh      # Windows: setup.bat
./run.sh        # Windows: run.bat
Scan only code you own or have permission to test.
